# Antigravity

https://antigravity.google/docs/getting-started

## Customizations

```
# MCP
~/.gemini/config/mcp_config.json                 # Global

# Skills
~/.gemini/config/skills/<skill-folder>/          # Global
<workspace-root>/.agents/skills/<skill-folder>/  # Workspace-specific

# Rules
~/.gemini/GEMINI.md                              # Global
<workspace-root>/.agents/rules/                  # Workspace-specific
```
