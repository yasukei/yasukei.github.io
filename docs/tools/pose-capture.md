# ポーズ推定（画面共有）

画面共有した動画から選択した範囲を切り出し、MediaPipe で推定した骨格をリアルタイムに重ねて表示します。ローカルの VRM モデルを読み込むと、追跡結果に合わせて頭・体幹・腕・脚・手首・指・表情が動きます。

1. PC の Chrome で「画面共有を開始」を押します。
2. YouTube などを開いた別のタブ、ウィンドウ、または画面を選びます。
3. プレビューの青い枠を移動・リサイズして、切り出した映像を確認します。
4. 追跡対象の Pose（全身）／Face（顔・表情）／Hand（手・指）を選び、「追跡を開始」を押します。複数を同時に有効にでき、追跡中も個別に ON／OFF できます。初期設定は Pose のみです。
5. 「VRM ファイル」で手元の `.vrm` を選びます（VRM 0.x / 1.0 対応）。骨格と並べて同期表示します。
6. 終わったら「共有を停止」、またはブラウザの共有停止ボタンを押します。

このページ自身を共有すると映像が入れ子になるため、別のタブやウィンドウを選んでください。共有元の選択と許可は開始するたびに必要です。DRM で保護された動画などは黒く表示されることがあります。スマートフォンは対象外です。

ポーズ推定には Pose Landmarker を使用し、1 人を対象に処理します。推定モデルは Lite（初期設定・速度優先）／Full（バランス）／Heavy（精度優先・高負荷）から選べます。推定中に変更するとモデルを読み替えて再開します。各モデルの初回利用時はダウンロードが必要です。GPU が利用できない場合は CPU での初期化を試みます。推定中は処理負荷に応じて FPS が下がる場合があります。

VRM の駆動には 3D の worldLandmarks を使い、回転を平滑化しています。単眼推定のため奥行きや関節のねじれは正確に再現できません。ルート移動は対象外です。Face を有効にすると、顔の向き・まばたき・口の開閉や形・笑顔を VRM の対応する表情に割り当てます。Hand は手首と指を動かします。表情や指の再現はモデルに対応する表情・ボーンがある場合に限られます。手首の回転には、手のひらの向きを定める人差し指・中指・小指の付け根のボーンも必要です。低確度の関節や推定停止時は最後の姿勢を保持します。「ポーズをリセット」で初期姿勢に戻せます（推定中は次の結果で同期が再開します）。モデルとテクスチャを一つにまとめた VRM を使用してください。ファイルのアップロードは行いません。

Face は 1 顔、Hand は最大 2 手を検出します。Face や Hand だけでも動作しますが、独立した推定器のため、複数人が映ると別の人物を追跡する場合があります。1 人を対象にし、顔や手が十分な大きさに映るように枠を調整してください。Pose と Hand を併用する場合は、Pose の手首位置を使って左右を対応付けます。各推定器は同じ切り出し映像を入力に使い、個別に FPS を表示します。同時使用や Heavy モデルは負荷が高くなります。モデルの読み込みに失敗した場合は「追跡を開始」で失敗した推定器だけを再試行できます。OFF にするとその推定器を解放します。顔が未検出または OFF になると VRM の表情は解除します。
