# Project Roadmap

This page outlines the project goals, planned subsystems, and the technical roadmap for Yasukei's Wiki.

## Project Overview

This project is a personal GitHub Pages website serving as a multi-purpose platform for technical knowledge, web-based utility tools, and browser games.

## Technology Stack

- **Framework:** [VitePress](https://vitepress.dev/) (Vue 3 + Vite)
- **Architecture:** Static Site Generation (SSG)
- **Hosting:** GitHub Pages
- **Package Management:** npm

## Planned Subsystems

### 1. Wiki Subsystem
A central repository for notes, memos, and deep-dives into web technologies.
- **Features:** Markdown-based content, global search, sidebar navigation.

### 2. Tools Subsystem
Useful utility applications executed entirely in the client's browser.
- **Planned Tools:**
  - Markdown Previewer
  - Data Converter (JSON/XML, Base64)
  - Binary Viewer / Editor

### 3. Games Subsystem
Lightweight browser games for casual entertainment.
- **Planned Games:**
  - Minesweeper
